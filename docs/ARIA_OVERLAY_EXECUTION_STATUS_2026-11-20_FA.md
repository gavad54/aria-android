## بلوغ اجرای واقعی در کد

- **۷۲ از ۷۲ Overlay** اکنون به Handler دامنه‌ای اختصاصی و tenant-scoped متصل‌اند و مسیر API اجرای آن‌ها نیز به همین Runtime متصل شده است.
- **صفر از ۷۲ Overlay** بدون Handler دامنه‌ای باقی مانده‌اند؛ هر ۷۲ شناسه به Handler اختصاصی متصل شده‌اند.
- هر ۷۲ ورودی کاتالوگ تجاری در Registry وجود دارند و به Handlerهای ماژولی متصل‌اند؛ این موضوع اثبات فعال‌سازی سرویس بیرونی یا Production نیست.
- تعداد ماژول‌های تأییدشده در Production همچنان **صفر** است.

### پوشش ۷۲ Overlay

هر ۷۲ شناسه Overlay اکنون با Dispatch مبتنی بر شناسه دقیق به منطق اختصاصی متصل است. مسیر `POST /api/aria-expansion/modules/{moduleId}/run` پس از احراز هویت، خروجی دامنه‌ای را تولید و به‌صورت Work Item در پایگاه داده ذخیره می‌کند. شناسه Actor و Tenant از حساب احرازشده گرفته می‌شود و محدوده فعلی `PERSONAL_ACCOUNT_SCOPE` است؛ سازمان‌دهی چندکاربره هنوز تأیید نشده است. ماژول‌های نیازمند رضایت بدون `consent: true` اجرا نمی‌شوند. این پوشش به معنی فعال‌سازی سرویس بیرونی یا تأیید Production نیست.

## مواردی که هنوز تکمیل‌شده محسوب نمی‌شوند

این آزمون‌ها موارد زیر را اثبات نمی‌کنند:

۱. استقرار Production یا تطابق Commit عملیاتی با Commit تأییدشده.
۲. ساخت نسخه نهایی Android، امضای رسمی، نصب روی دستگاه و UAT.
۳. اجرای Migration واقعی پایگاه داده، آزمون نفوذ جداسازی Tenant و تمرین Restore.
۴. اتصال واقعی درگاه پرداخت، اشتراک، پیام‌رسانی، رزرو، انتشار یا تأمین‌کنندگان.
۵. مانیتورینگ Production، شواهد Backup/Restore، کارایی و گواهی امنیت.
۶. ادغام PR و تأیید مالک.

در Handlerهای جدید، عملیات بیرونی غیرفعال است و فقط خروجی قابل بازبینی تولید می‌شود. پرداخت، رزرو، اعلان، انتشار، حذف داده یا تأیید Production انجام نمی‌شود.

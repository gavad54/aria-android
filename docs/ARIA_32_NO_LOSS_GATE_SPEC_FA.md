# مشخصات گیت عدم حذف قابلیت‌های ARIA 32

**نسخه منبع:** 32.0.0  
**تعداد baseline:** 639 شناسه  
**SHA-256 مجموعه مرتب شناسه‌ها:** `f3be35b08164d22dc7ca99c875be340efc03021d8296edf05b4eb47b6565cf0b`

## کنترل‌های خودکار
- تعداد رکورد هر سه رجیستری Android، Backend و Capability باید دقیقاً 639 باشد.
- نسخه هر سه رجیستری باید 32.0.0 باشد.
- versionCode رجیستری‌های Android و Backend باید 320000 باشد.
- شناسه‌ها باید یکتا و در هر سه رجیستری کاملاً همسان باشند.
- digest مجموعه شناسه‌ها باید با baseline بالا برابر باشد تا حذف یا جایگزینی شناسه قدیمی شناسایی شود.
- نام هر قابلیت در رجیستری اصلی و capability contract باید یکسان باشد.
- فیلدهای قرارداد، امنیت، revenue guardrails و implementation wave باید موجود باشند.
- گیت تصریح می‌کند ACTIVE در metadata اثبات اجرای واقعی یا آمادگی Production نیست.

## اجرای آزمون
`node scripts/aria32_no_loss_gate.js`

این گیت در readiness suite و Android workflow اجرا می‌شود. هر تغییر عمدی در baseline نیازمند ممیزی و نسخه‌بندی صریح است؛ baseline نباید برای سبزکردن آزمون بدون شواهد تغییر کند.

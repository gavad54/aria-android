# ممیزی بلوغ اجرایی ۸۹۳ واحد ARIA — ۲۰۲۶-۱۱-۲۰

## هدف و قاعده شمارش

این گزارش بین «وجود در رجیستری»، «وجود مسیر اجرای محلی»، «وجود منطق سطح خانواده/دامنه»، «منطق اختصاصی هر واحد»، «اتصال بیرونی»، «تجاری‌سازی واقعی» و «تأیید Production» تفاوت می‌گذارد. هیچ‌یک از این وضعیت‌ها جایگزین دیگری نیست.

| گروه | تعداد | نوع اجرای قابل اثبات فعلی | تعداد handler اختصاصی هر واحد |
|---|---:|---|---:|
| ماژول‌های canonical | 639 | گردش‌کار محلی مبتنی بر 15 خانواده canonical | 0 |
| overlayهای تحت مالکیت ARIA | 72 | آماده‌سازی work item محلی؛ هنوز اجرای منطق تخصصی دامنه اثبات نشده | 0 |
| کاتالوگ تجاری | 72 | adapter محلی در 13 پروفایل دامنه | 0 |
| موتورهای فرزند | 71 | adapter محلی در 4 خانواده موتور | 0 |
| ماژول‌های افزوده جدید | 39 | 39 handler مستقل دامنه‌ای با اجرای محلی و آزمون برای هر واحد | 39 |
| **جمع مالکیت ARIA** | **893** | مسیرهای محلی با سطوح بلوغ متفاوت؛ 39 واحد دارای منطق دامنه‌ای مستقل | **39 handler مستقل محلی** |

## تفکیک موجودی

- 639 canonical ثابت و حفظ‌شده است.
- 111 رکورد overlay تاریخی حفظ شده‌اند؛ 72 مورد متعلق به ARIA، 36 مورد متعلق به محصولات خواهر و 3 مورد آرشیوی هستند.
- 72 ماژول تجاری و 71 موتور فرزند در شمارش سلسله‌مراتبی قرار دارند.
- 39 ماژول افزوده جدید جایگزین 39 رکورد lineage منتقل‌شده/آرشیوی در شمارش مالکیت ARIA شده‌اند؛ این 39 رکورد lineage همچنان در تاریخچه کل باقی می‌مانند.
- بنابراین کل رکوردهای موجودی 932 است: 893 واحد تحت مالکیت ARIA و 39 رکورد lineage خارج از مالکیت ARIA.
- 71 موتور فرزند entitlement مستقل قابل‌فروش ندارند و باید از entitlement والد استفاده کنند؛ تعداد entitlementهای جداگانه 822 است.

## آنچه اکنون واقعاً اثبات شده

1. هر 893 واحد شناسه و رکورد رجیستری یکتا دارند.
2. برای هر 893 واحد مسیر محلی در رجیستری اجرایی تعریف شده است؛ «مسیر محلی» به‌تنهایی اثبات اجرای عملیات تخصصی نیست.
3. 639 واحد canonical از 15 handler خانواده‌ای استفاده می‌کنند؛ هنوز handler اختصاصی مستقل برای هر یک از 639 واحد وجود ندارد.
4. 72 ماژول تجاری از 13 پروفایل adapter دامنه‌ای استفاده می‌کنند؛ این‌ها 72 منطق مستقل و مجزا نیستند.
5. 71 موتور در 4 خانواده موتور مسیر adapter محلی دارند؛ این موضوع به معنی اتصال provider یا نتیجه واقعی بیرونی نیست.
6. 72 overlay و 39 ماژول افزوده فعلاً در سطح آماده‌سازی work item محلی هستند.
7. شمار تأییدشده Production، اتصال provider بیرونی و پرداخت واقعی در این ممیزی صفر است. پرداخت و صورتحساب عمداً غیرفعال‌اند و قیمت‌ها تا تعیین مالکانه خالی می‌مانند.

## API ممیزی

مسیر `GET /api/aria-expansion/implementation-maturity` شمارش بالا را به‌صورت ماشین‌خوان ارائه می‌کند. آزمون API، تعدادها، سطح اجرای هر گروه، نبود پرداخت زنده و صفر بودن تأیید Production را بررسی می‌کند.

## گیت‌های لازم برای رسیدن به «۸۹۳ واحد دارای عملکرد تخصصی اثبات‌شده»

1. برای هر 893 شناسه، crosswalk به یک handler دامنه‌ای مشخص و مرز عدم‌همپوشانی ثبت شود.
2. برای هر واحد، منطق ورودی/خروجی و عملیات واقعی دامنه اجرا شود؛ ساختن فهرست گام‌ها به‌تنهایی کافی نیست.
3. آزمون رفتاری مثبت، ورودی نامعتبر، خطای دامنه، tenant isolation و ممیزی برای هر واحد اضافه شود.
4. اجرای end-to-end روی پایگاه داده واقعی و سناریوهای کاربری انجام شود.
5. اتصال providerها فقط با مجوز و secrets امن مالک و با least privilege انجام شود.
6. قیمت، entitlement، مالیات، بازپرداخت، metering و کنترل سوءاستفاده قبل از فعال‌سازی پرداخت نهایی شوند.
7. backup/restore، امنیت Production، MFA، Android build/signing و UAT با شواهد مستقل PASS شوند.

# گزارش مهندسی اتصال ۷۲ قابلیت کاتالوگ وب ARIA به قراردادهای نسخه ۳۲

تاریخ بررسی: ۲۰۲۶-۱۱-۱۹  
وضعیت: اصلاحات وب و آزمون‌های مربوطه در شاخه مهندسی ثبت شده‌اند؛ ادغام و انتشار انجام نشده است.

## ۱. دامنه و نتیجه قابل اثبات

- کاتالوگ وب شامل ۷۲ قابلیت با شناسه‌های ۶۵۱ تا ۷۲۲ است.
- هر رکورد به یک قرارداد با `capabilityContractId` متصل است.
- برای قابلیت‌های هم‌پوشان، `aliasOfModuleId` به یکی از قراردادهای قدیمی ارجاع می‌دهد؛ وجود alias به معنی حذف قابلیت پایه نیست.
- رجیستری هدف پس از اعمال overlay برابر ۷۱۱ قرارداد است: ۶۳۹ قرارداد پایه + ۷۲ قرارداد کاتالوگ وب.
- هفت نام محصولی قدیمی از نام‌گذاری عمومی ARIA کنار گذاشته شده‌اند و قابلیت‌های متناظر در حوزه‌های عمومی ARIA ارائه می‌شوند.
- فیلد `legacyProduct` از پاسخ عمومی API حذف شده است.
- اسکریپت overlay اکنون وجود و اعمال واقعی هر anchor اصلاحی را کنترل می‌کند؛ اگر anchor مورد انتظار پیدا نشود یا اصلاح اعمال نشود، اجرای آن با خطا متوقف می‌شود.

## ۲. رفتار اجرایی که واقعاً پیاده‌سازی شده

- `GET /api/modules`: فهرست ۷۲ قابلیت و شناسه قرارداد مربوط را ارائه می‌کند.
- `GET /api/modules/summary`: تعداد کاتالوگ، دامنه‌ها، وضعیت گردش‌کار محلی و محدودیت‌ها را گزارش می‌کند.
- `POST /api/modules/:contractId/plan`: یک برنامه/گردش‌کار محلی ساختاریافته بر اساس دامنه تولید می‌کند.
- `ACTIVE_LOCAL_WORKFLOW` به معنی اجرای واقعی سرویس بیرونی نیست.
- انتشار در شبکه‌های اجتماعی، رندر رسانه، رزرو، پرداخت، تسویه، عملیات ابری یا تراکنش بیرونی انجام نمی‌شود؛ این موارد تا وجود adapter رسمی، مجوز محدود و آزمون مستقل مسدود هستند.
- ثبت قابلیت در manifest یا فعال بودن metadata به‌تنهایی اثبات‌کننده تکمیل عملیاتی، درآمد واقعی یا آماده‌بودن برای Production نیست.

2. شاخه `engineering/aria-preserve-all-capabilities-2026-11-19` را انتخاب کنید.
3. از **Add file → Upload files** فایل ZIP را بارگذاری کنید.
4. مسیر مقصد را `release-input/` و نام فایل را دقیقاً `ARIA_32_RUNTIME_FIXES_RELEASE_READINESS_SOURCE.zip` قرار دهید.
5. Commit را روی همان شاخه انجام دهید.

پس از بارگذاری، workflow اندروید با کنترل SHA-256 اجرا می‌شود. اگر checksum یا هر گیت فنی شکست بخورد، انتشار متوقف می‌ماند و باید خطا بر اساس log اصلاح شود.

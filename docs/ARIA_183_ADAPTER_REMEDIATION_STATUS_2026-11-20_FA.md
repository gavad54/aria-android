# گزارش اجرایی تبدیل Adapterهای اولیه ARIA — ۲۰۲۶-۱۱-۲۰

## دامنه و روش شمارش

هدف اصلی، تبدیل ۱۸۳ Adapter اولیه به قابلیت‌های دامنه‌ای اختصاصی است: ۴۰ ماژول ایده، ۷۲ ماژول کاتالوگ تجاری و ۷۱ موتور فرزند. شمارش «منطق دامنه‌ای محلی» از «تأیید Production» جداست. هیچ پرداخت، انتشار بیرونی یا اجرای provider صرفاً با موفقیت تست محلی فعال تلقی نمی‌شود.

## پیشرفت تأییدشده در این commit

- ۴۰/۴۰ ماژول ایده در cohort اولیه دارای handler دامنه‌ای اختصاصی‌اند.
- ۵۰/۷۲ ماژول کاتالوگ (شناسه‌های ۶۵۱ تا ۷۰۰) دارای handler اختصاصی و تست رفتاری‌اند.
- ۷۱/۷۱ موتور فرزند دارای handler دامنه‌ای اختصاصی و آزمون رفتاری‌اند.
- در مجموع cohort اصلی: ۱۶۱/۱۸۳ تکمیل منطق دامنه‌ای محلی؛ ۲۲ مورد باقی‌مانده.
- رجیستری کل ۲۰۱ ماژول Backend: ۱۷۹ DOMAIN_LOGIC_LOCAL و ۲۲ DOMAIN_ADAPTER_LOCAL. این عدد ۱۳۸ شامل ۱۰ ماژول ایده افزوده، ۴ کنترل حاکمیتی و ۴ موتور تحویل خدمت نیز هست؛ بنابراین نباید آن را به‌جای ۸۰/۱۸۳ cohort اصلی گزارش کرد.
- ۶۳۹ رکورد canonical و ۲۰۱ ماژول Backend حفظ شده‌اند.
